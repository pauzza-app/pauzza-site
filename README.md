# pauzza.ge

The website for Pauzza, an opt-in add-on that turns the wait in your AI coding tool into offers and promo codes.

This is a test version: every offer and code is made up.

- Static files only. No build step, no trackers, no cookies, no analytics, and nothing loaded from other sites.
- To preview, open `index.html` in a browser.
- The add-on itself lives at [pauzza-app/pauzza-addon](https://github.com/pauzza-app/pauzza-addon).
