// install

One line. Copy, paste, done.

Nothing starts by itself: Pauzza stays silent until you type /pauzza and accept the Terms.

claude plugin install pauzza --marketplace pauzza-app/pauzza-marketplace
  1. 01Paste it into your terminal and press Enter.
  2. 02Open your AI coding tool and type /pauzza. If it was already open, type /reload-plugins first.

Other ways

Without the terminal

Type this in the chat box of an open session. The tool asks you to confirm the new source, then installs.

/plugin install pauzza --marketplace pauzza-app/pauzza-marketplace

On an older version

The one-line install needs version 2.1.292 or later; Pauzza itself needs 2.1.287 or later. Check with claude --version. On an older version, run these two lines in a terminal instead.

claude plugin marketplace add pauzza-app/pauzza-marketplace
claude plugin install pauzza@pauzza

Remove it

Open /pauzza, press ⚙ and delete the saved data. Then run these two lines and restart the app.

claude plugin uninstall pauzza@pauzza
claude plugin marketplace remove pauzza

The only official copy is github.com/pauzza-app/pauzza-addon, installed through pauzza-app/pauzza-marketplace. Pauzza never asks for your card details or passwords.

// privacy

What Pauzza will never do.

Six promises, in plain words. Each one is written down in the add-on's own README and Privacy Policy, and you can check them against the code.

  • It never reads your work

    Not your code, not your prompts, not your conversations, not your files. It reads usage numbers and whether the tool is busy, and those stay on your computer.

  • Nothing is sent before Connect

    Installing sends nothing. Accepting the Terms sends nothing. The add-on contacts Pauzza's server only after you press the separate Connect button.

  • Offers never reach the AI

    Offers are shown to you, beside the tool. Pauzza never puts them into anything the AI reads.

  • Opt-in, twice

    Nothing runs until you accept. If you press Not now, it stays silent. Connecting is a second choice, and closing the panel declines it.

  • No name, no profile

    After Connect the server keeps a random number for your install and the test codes you claim. No name, phone or payment details. We build no profile of you and sell nothing.

  • One switch to leave

    Under ⚙ there is one switch. It stops Pauzza, disconnects it, and asks the server to delete your install record. Free, at any time.

Like any internet request, a connected add-on shows the server your IP address; our hosting keeps it in technical logs for at most 7 days. The add-on's code is open under the MIT licence, so these are promises you can check by reading it. The full text is in the Privacy Policy.
